## Como usar este documento

Cada card abaixo já vem com **5 peças prontas**:

| Campo | O que é |
|---|---|
| **Tipo** | formato do card (Mito×Verdade, Número da Semana, etc.) |
| **Tarja** | etiqueta de tema no topo (TRABALHO • SAÚDE • DEMOCRACIA…) |
| **Manchete** | título curto e forte (Anton, CAIXA ALTA, máx. ~7 palavras) |
| **Dado + Fonte** | a linha de apoio com número real **já pesquisado e datado** |
| **Legenda** | texto pronto pra copiar/colar no post |

🔴 **Trava de conformidade (a regra que vence):** todo número aqui já tem fonte e ano.
Onde aparece `⚠️ VERIFICAR`, **o número ainda precisa ser confirmado na fonte oficial antes de virar arte** — não publique sem fechar.
Os dados deste documento foram coletados em **junho/2026**; antes de uma campanha, reconfira se saiu número mais novo.

A lista completa de fontes com link está no fim do arquivo (**[§ Fontes](#fontes-consultadas)**).

## Referência rápida de marca

- **Cores:** vermelho `#C20019` / `#E60A1F` · vermelho escuro `#5E000B` · preto `#0C0405` · creme `#EFE9DD` · amarelo/ouro `#FFC400` (destaque).
- **Fontes:** títulos em **Anton** (condensada, pesada, CAIXA ALTA); texto em **Inter** (bold/semibold).
- **Assinatura:** ★ amarela + logo **POVO JÁ** + `@` em todo card. Punho ✊ como elemento de força.
- **Estética:** cartaz popular / pôster de campanha — alto contraste, fundo vermelho ou preto, texto creme, manchete amarela. Selo de fonte sempre visível quando houver dado.
- **Formatos:** Feed 1:1 `1080×1080` · Story/Reels 9:16 `1080×1920` (≈250px livres no topo e base) · Carrossel 4:5 `1080×1350`.

### Modelo de legenda padrão

```

📊 [dado + fonte + ano]
👉 Compartilha com quem precisa ler isso ✊
#PovoJá #[tema] #Brasil
```

# Regras de ouro · checklist pré-publicação

Antes de exportar qualquer card, confira:

- [ ] **Tem dado?** → tem **fonte + ano** visível na peça?
- [ ] O número foi **confirmado na fonte oficial** (não há `⚠️ VERIFICAR` pendente)?
- [ ] Uma ideia só por card? Manchete com ~7 palavras?
- [ ] Tem **CTA** (compartilhe / comente / siga)?
- [ ] Crítica a **ideias, partidos e governos** — sem difamar pessoa privada, sem incitar violência?
- [ ] **Sem** print falso de veículo, **sem** citação inventada, **sem** deepfake?
- [ ] Respeitou paleta e fontes da marca? Assinatura ★ POVO JÁ + `@` presente?
- [ ] Em período eleitoral: **sem** "digite o número do candidato" / pedido de voto vedado.
